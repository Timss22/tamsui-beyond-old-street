# Photos go here

Drop your own Tamsui photos into this folder, then point a place at one in
[`../../data/places.js`](../../data/places.js), e.g.:

```js
image: "assets/img/fort-san-domingo.jpg"
```

Until a photo is added, each card shows a clean category gradient + icon — so the
site looks complete with no photos at all. Recommended size: roughly **800 × 500 px**.
